📍 Topologias e Componentes de Rede

Aula 2 — Topologias físicas e lógicas em profundidade, dispositivos de rede (hub, switch, roteador, modem) e fundamentos de cabeamento estruturado

📐 Topologia Física vs Topologia Lógica

É fundamental distinguir dois conceitos que frequentemente são confundidos:

🧱 Topologia Física

Descreve como os dispositivos estão fisicamente conectados — o layout real dos cabos, switches e equipamentos. É o que você vê ao olhar para a sala ou rack de servidores.

📊 Topologia Lógica

Descreve como os dados fluem pela rede — o caminho que a informação percorre independentemente de como os cabos estão dispostos fisicamente.

💡 Exemplo clássico: Uma rede Ethernet moderna usa topologia física estrela (todos os cabos vão ao switch central), mas a topologia lógica é de barramento (os dados são transmitidos para todos e cada dispositivo verifica se o pacote é seu). Em redes modernas com switches, até essa distção é superada pela comutação seletiva.

🕸️ Topologias em Detalhe

⭐ Estrela (Star)

Todos os dispositivos se conectam a um ponto central (switch ou hub). É a topologia dominante nas LANs modernas.

Diagrama — Topologia Estrela
        [PC-1]
           |
[PC-2] --[SWITCH]-- [PC-3]
           |
        [PC-4]
VantagensDesvantagens
Falha em um cabo não afeta os demais Switch central é ponto único de falha
Fácil de adicionar/remover dispositivos Maior quantidade de cabeamento
Fácil de diagnosticar problemas Custo do switch central

🚦 Barramento (Bus)

Todos os dispositivos compartilham um único cabo (backbone). Quando um dispositivo transmite, todos os outros recebem o sinal.

Diagrama — Topologia Barramento
[PC-1]--[PC-2]--[PC-3]--[PC-4]
|___________________________|
       Cabo coaxial
VantagensDesvantagens
Simples e barata de implementar Falha no cabo central derruba toda a rede
Poucos cabos necessários Desempenho cai com mais dispositivos
Adequada para redes pequenas Praticamente obsoleta

🔁 Anel (Ring)

Os dispositivos formam um círculo fechado. Cada nó recebe e regenera o sinal antes de passá-lo adiante. Usada no padrão Token Ring (legado) e em redes SONET/SDH de alta disponibilidade.

Diagrama — Topologia Anel
   [PC-1]
   /     \
[PC-4] [PC-2]
   \     /
   [PC-3]
VantagensDesvantagens
Sem colisões (acesso controlado por token) Falha em um nó pode derrubar o anel
Desempenho previsível sob carga Adicionar dispositivos interrompe a rede
Anel duplo oferece redundância Tecnologia em desuso nas LANs

🧶 Malha (Mesh)

Cada dispositivo possui conexões diretas com vários outros. Na malha completa (full mesh) todos se conectam a todos. Na malha parcial (partial mesh) apenas alguns nós têm múltiplas conexões.

Diagrama — Malha Completa (4 nós)
[A]---[B]
 | \ / |
 |  X  |
 | / \ |
[D]---[C]

✅ Fórmula: Em uma malha completa com n dispositivos, o número de conexões necessárias é n(n−1)/2. Com 10 dispositivos: 10×9/2 = 45 conexões. Por isso a malha é usada no backbone da internet, não em redes locais.

🌱 Estrela Estendida (Hierárquica)

Na prática, a maioria das redes corporativas e escolares usa uma estrela estendida: switches conectados a outros switches, formando camadas (acesso, distribuição e núcleo).

🧩 Dispositivos de Rede em Profundidade

Hub — Concentrador (Legado)

O hub é o dispositivo mais simples: ao receber um sinal em uma porta, ele replica para todas as outras portas sem nenhum tipo de filtragem. Isso cria um único domínio de colisão para todos os dispositivos conectados.

⚠️ Por que o hub é obsoleto? Com um hub, se dois dispositivos transmitem ao mesmo tempo ocorre uma colisão: os dados são corrompidos e precisam ser retransmitidos. Quanto mais dispositivos, mais colisões e pior o desempenho. O switch resolve completamente esse problema.

Switch — Comutador

O switch aprende o endereço MAC de cada dispositivo e encaminha os quadros somente para a porta correta. Cada porta forma seu próprio domínio de colisão — praticamente eliminando as colisões.

🔒 Switch Não Gerenciável

  • Liga e funciona (plug and play)
  • Sem configuração necessária
  • Sem suporte a VLANs
  • Ideal para redes domésticas e pequenos escritórios

⚙️ Switch Gerenciável

  • Configurável via CLI ou interface web
  • Suporte a VLANs, QoS, STP, SNMP
  • Monitoramento de tráfego por porta
  • Indispensável em redes corporativas
Como o switch aprende endereços MAC
1. PC-A envia quadro para PC-B
2. Switch recebe na porta 1 e registra: "MAC de A = porta 1"
3. Switch ainda não sabe onde está B: envia para TODAS as portas (flooding)
4. PC-B responde: switch registra "MAC de B = porta 2"
5. Próxima vez: switch envia diretamente porta 1 → porta 2
   (sem flooding, sem colisão com os demais)

Roteador — Router

O roteador opera na Camada 3 (Rede) e conecta redes diferentes. Enquanto o switch usa endereços MAC para encaminhar dentro de uma rede, o roteador usa endereços IP para encaminhar entre redes.

Roteamento Encaminhamento IP Decide o melhor caminho para cada pacote usando tabelas de roteamento
NAT Tradução de Endereços Permite que vários dispositivos compartilhem um único IP público
DHCP Distribuição de IP Roteadores domésticos geralmente incluem servidor DHCP integrado
Firewall Filtragem básica Roteadores modernos têm ACLs e filtragem de pacotes integradas

Modem — Modulador/Demodulador

O modem converte os sinais digitais do computador no formato adequado para o meio físico da operadora (linha telefônica, cabo de TV, fibra óptica). Em redes modernas, o modem é frequentemente integrado ao roteador em um único equipamento.

Dispositivo Camada OSI Identificação usada Função principal
Hub Camada 1 (Física) Nenhuma Replica sinal para todas as portas
Switch Camada 2 (Enlace) Endereço MAC Encaminha quadros seletivamente
Roteador Camada 3 (Rede) Endereço IP Interliga redes distintas
Modem Camada 1 (Física) Nenhuma Adapta o sinal ao meio da operadora

🧵 Cabeamento Estruturado

O cabeamento estruturado é um sistema padronizado de cabos e conexões que suporta múltiplos serviços (dados, voz, vídeo) de forma organizada e flexível. O principal padrão é o ANSI/TIA-568.

Categorias de Cabo UTP

Categoria Velocidade máx. Frequência Uso típico
Cat 5e 1 Gbps 100 MHz Redes domésticas e escritórios (ainda muito comum)
Cat 6 10 Gbps (até 55m) 250 MHz Redes corporativas modernas
Cat 6A 10 Gbps (até 100m) 500 MHz Data centers e redes de alto desempenho
Cat 7 10 Gbps 600 MHz Ambientes com alta interferência eletromagnética

Pinagem RJ-45: T568A e T568B

O conector RJ-45 tem 8 pinos. Existem dois padrões de pinagem definidos pela TIA-568:

🟢 Padrão T568B (mais comum no Brasil)

  • Pino 1: Laranja/Branco
  • Pino 2: Laranja
  • Pino 3: Verde/Branco
  • Pino 4: Azul
  • Pino 5: Azul/Branco
  • Pino 6: Verde
  • Pino 7: Marrom/Branco
  • Pino 8: Marrom

🟡 Padrão T568A

  • Pino 1: Verde/Branco
  • Pino 2: Verde
  • Pino 3: Laranja/Branco
  • Pino 4: Azul
  • Pino 5: Azul/Branco
  • Pino 6: Laranja
  • Pino 7: Marrom/Branco
  • Pino 8: Marrom

Cabo Direto vs Cabo Crossover

➡️ Cabo Direto (Straight-through)

Ambas as pontas com o mesmo padrão (T568B–T568B ou T568A–T568A). Conecta dispositivos diferentes: computador → switch, switch → roteador.

⇄ Cabo Crossover

Uma ponta T568A e outra T568B. Conecta dispositivos do mesmo tipo: computador → computador, switch → switch. Hoje em dia, a maioria dos dispositivos detecta automaticamente (Auto-MDI/MDIX).

✅ Distância máxima: O cabo UTP tem limite de 100 metros por segmento para garantir a integridade do sinal. Além disso, é necessário um repetidor, switch ou conversor para fibra óptica.

📝 Atividade Prática

Identificação de dispositivos e criação de diagrama de rede real.

1
Identificar dispositivos no laboratório
Observe os equipamentos do laboratório e identifique: qual o modelo do switch? Ele é gerenciável ou não? Há roteador? Há access point? Registre marca, modelo e número de portas de cada equipamento encontrado.
2
Examinar um cabo UTP
Pegue um cabo UTP com conector RJ-45 e observe a pinagem (olhe pelas laterais do conector). Identifique o padrão: T568A ou T568B? O cabo é direto ou crossover? Qual a categoria do cabo (geralmente está escrito no próprio cabo)?
3
Desenhar o diagrama de rede
Com base no que observou, desenhe o diagrama de rede do laboratório usando símbolos padrão (retângulo para PCs, quadrado com setas para switch, cilindro para servidor). Indique a topologia física.
4
Calcular conexões de malha
Usando a fórmula n(n−1)/2, calcule quantas conexões seriam necessárias para criar uma malha completa com todos os computadores do laboratório. Esse número é viável na prática? Justifique.
5
👥 Trabalho em grupo — Projeto de rede para um cenário real
(Aprendizagem Baseada em Problemas — grupos de 3–4 alunos) Cenário: uma escola pequena quer montar uma nova sala de informática com 20 computadores, impressora em rede e acesso à internet. O grupo deve: (a) escolher a topologia física; (b) listar os equipamentos necessários (switch, roteador, cabos, conector RJ-45); (c) justificar cada escolha. Apresentem a proposta para a turma e debatam as diferenças entre os grupos. Interdisciplinaridade: pesquisem preços reais e calculem o custo estimado da instalação.
6
🧩 Computação desplugada — Simulação hub vs switch
(Metodologia ativa — sem computador) Em duplas, simule o comportamento de um hub e de um switch usando papel e caneta. Desenhe 4 dispositivos e trace as setas de tráfego: (a) com hub, quando PC-A envia para PC-B, quem recebe o dado? (b) com switch, após aprender os MACs, quem recebe? Calculem: em uma rede com hub e 10 dispositivos transmitindo ao mesmo tempo, quantas colisões poderiam ocorrer? Reflit am sobre como esse problema é resolvido pelo switch. A atividade pode ser realizada com figuras táteis por alunos com deficiência visual.
📌 Para refletir: a escolha entre hub e switch pode parecer simples hoje, mas no final dos anos 90 switches eram caros e hubs eram comuns. Entender por quê o switch venceu é entender um dos princípios mais importantes de redes: eliminar colisões aumenta dramaticamente o desempenho.

❓ Verifique seu Conhecimento

Qual é a principal diferença entre um hub e um switch?

AO switch conecta redes diferentes usando endereços IP
BO hub é mais rápido pois não processa os endereços
CO switch encaminha quadros seletivamente pelo endereço MAC, eliminando colisões
DO hub suporta VLANs enquanto o switch não suporta
✓ O switch aprende os endereços MAC de cada porta e encaminha quadros somente para a porta correta, criando domínios de colisão individuais. O hub replica para todas as portas, gerando colisões e desperdiçando banda.

Para conectar dois computadores diretamente, sem usar switch, qual tipo de cabo UTP deve ser utilizado?

ACabo direto (straight-through) T568B–T568B
BCabo crossover T568A–T568B
CCabo coaxial com conector BNC
DCabo direto T568A–T568A
✓ O cabo crossover (uma ponta T568A e outra T568B) é usado para conectar dispositivos do mesmo tipo — como computador a computador ou switch a switch — sem a necessidade de um dispositivo intermediário.

Uma empresa possui sede em São Paulo e filial no Rio de Janeiro. A rede que interliga as duas unidades é classificada como:

ALAN — Local Area Network
BPAN — Personal Area Network
CMAN — Metropolitan Area Network
DWAN — Wide Area Network
✓ Uma rede que conecta localidades geograficamente distantes (cidades, estados ou países) é classificada como WAN (Wide Area Network). A internet é o maior exemplo de WAN existente.

Qual topologia de rede é usada no backbone da internet, garantindo múltiplos caminhos alternativos entre os nós?

AMalha (Mesh)
BEstrela (Star)

DAnel (Ring)
✓ A topologia em malha é usada no backbone da internet pois oferece múltiplos caminhos entre os nós. Se um link falha, o tráfego é redirecionado automaticamente — exatamente o princípio que motivou a criação da ARPANET.
